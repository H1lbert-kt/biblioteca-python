# Sistema de Biblioteca em Python

Projeto simples de gerenciamento de biblioteca feito em Python com o objetivo de praticar fundamentos da linguagem e organização de código.

## Funcionalidades

* Cadastrar livros
* Listar livros
* Buscar livro pelo título
* Emprestar livro
* Devolver livro
* Visualizar livros emprestados
* Visualizar livros disponíveis

## Estrutura do Projeto

```
biblioteca-python

main.py          # Arquivo principal do programa (menu e execução)
biblioteca.py    # Funções responsáveis pela lógica da biblioteca
```

## Tecnologias utilizadas

* Python 3
* Programação modular (separação de arquivos)

## Como executar

1. Clone o repositório:

```
git clone https://github.com/H1lbert-kt/biblioteca-python.git
```

2. Entre na pasta do projeto:

```
cd biblioteca-python
```

3. Execute o programa:

```
python main.py
```
